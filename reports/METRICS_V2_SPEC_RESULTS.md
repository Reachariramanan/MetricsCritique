## 10. Exposure offset (F2) — deviation from the spec

The spec names `collection_effort` as the exposure offset. It cannot serve that role on the posted-day grain, measured:

- it is keyed on **scrape day**, not posted day: only 781 of 8647 platform-days in the panel have a row (8 of 45 Telegram posted-days);
- `active_channels = 0` on 5 of Telegram's 8 rows despite thousands of ingested rows;
- where both exist, observed and reported active channels correlate 0.805 overall, but per-platform baidu_tieba: 0.96 (n=4), facebook: 0.56 (n=88), facebook_profile: 0.11 (n=38), instagram: 0.44 (n=57), linkedin: 0.42 (n=85), mastodon: 0.76 (n=31), pinterest: 1.00 (n=23), reddit: 0.91 (n=68), snapchat: 0.47 (n=12), telegram: 0.37 (n=65), tiktok: 0.43 (n=18), truthsocial: -0.04 (n=36), twitter: 0.83 (n=49), whatsapp: 1.00 (n=38), youtube_comment: 0.65 (n=102), youtube_video: 0.51 (n=66).

Splicing a partially-available series with a fallback would inject scale discontinuities indistinguishable from growth. `effort` is therefore the **observed** distinct active channels per platform-day — the same quantity the spec asks for, measured on the correct grain with 100% coverage — with `collection_effort` used only as the cross-check above. `effort_source` records this on every row. Consequence to note: `V_rate` is posts per active channel and is endogenous, so a coordinated burst from a *few* channels raises `V_rate` more than the same burst spread across many.

## 13. Flagged for the statistical review

1. **Overdispersion self-masking.** The NB baseline is fitted on the trailing 28 days including earlier spikes, so 1/θ absorbs them and depresses `surprise`: the largest value in the whole panel is 42.126 (p = 0.000000) even for a 35× excursion (t007/instagram, V = 124 vs μ = 8.2). A trimmed or winsorised baseline window would sharpen this; it is not implemented.
2. **`accel_smooth` window sensitivity** — corr(5, 7) = 0.431. Needs a principled window choice.
3. **Per-day BH has very low power** — m ≈ 10–15 supported cells per day. `surprise_q_global` is published alongside; the review should pick one.
4. **AR(1) on the level vs the difference** — see the `ar1_phi` caveat in `metric_meta`. The spec's differenced form yields a defined half-life on only 4/139 series.
5. **Kleinberg runs on raw counts**, so a rising collector ramp can inflate late burst states; the CUSUM path is effort-adjusted. Worth harmonising.
6. **`onset_slope` units are not comparable across `onset_method`** — 440/582 episodes use the log-linear fallback because rising limbs are 1–3 days in a 45-day window.
7. **`emergence_score` is a within-run rank**, so values are not comparable across runs as the panel grows.
8. **`coordination_flag` is a heuristic**, not a test; reddit (50%) and instagram (45%) baseline duplicate rates are feed artefacts.
